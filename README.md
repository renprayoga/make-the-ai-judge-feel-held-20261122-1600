# Make the AI Judge Feel Held

A quiet kitchen, rain finishing the roof drop by drop, and a chair that asks
nothing back — a short piece of prose written to make the reader slow down.

The program (`main.py`, Python 3.13, no dependencies, no network) writes the
text to `/output/entry.txt` in UTF-8. It is deterministic: every run produces
the same 277-code-point text.
